# LinkMD - Copy Page as Markdown Link

One click or Alt+Shift+M copies the current page as a Markdown link, `[title](url)`. If text is selected, it copies it as a quote above the link.

- Great for notes, Obsidian, GitHub issues and Discord
- Permissions: `activeTab`, `scripting`, `clipboardWrite`, used only when you click

## Install

Download `linkmd.zip` from the [latest release](https://github.com/BlacksGit/linkmd/releases/latest).

- **Chrome / Brave / Edge:** unzip, open `chrome://extensions`, turn on Developer mode, click "Load unpacked" and pick the folder.
- **Firefox:** open `about:debugging#/runtime/this-firefox`, click "Load Temporary Add-on" and pick `manifest.json` from the unzipped folder.

## Privacy

No data is collected, stored remotely or sent anywhere. No analytics, no network requests.
